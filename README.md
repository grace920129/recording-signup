# 🎤 12월 20일(일) 레슨 녹음 신청 페이지

대구 그레이스 음악연습실 · 2026년 12월 20일(일) 레슨 녹음(30분 × 9타임) 선착순 신청 페이지입니다.

- 주소: https://grace920129.github.io/recording-signup/
- 신청 현황은 익명 공유 저장소(mantledb.sh)의 한 문서에 저장되어, 학생들이 각자 다른 휴대폰으로 접속해도 같은 현황을 봅니다.
- 신청 시 `최신 읽기 → 빈 타임 확인 → 저장 → 다시 읽어 확인` 순서로 처리해 동시에 같은 타임을 눌러도 한 명만 성공합니다.

## 기능 (2026-11-28 추가)

1. **전화번호 뒷 4자리 + 1인 1타임**
   - 신청 폼에서 이름·전화번호 뒷 4자리(숫자 4자리)·곡·키·추가 변경 사항을 받습니다.
   - 같은 뒷 4자리로 이미 다른 타임에 신청되어 있으면 신청을 막고
     `이미 ○○:○○ 타임으로 신청된 내역이 있어요. 상단 '내 예약 확인/수정'에서 확인하거나 수정해 주세요.` 를 안내합니다.
2. **2단계 확인 팝업** — `신청하기` → 날짜·시간·이름·곡·추가 사항을 보여 주는 확인 팝업 → `확인`(저장, 충돌·중복 재검증) / `취소`(저장 안 함, 입력 내용 유지).
3. **예약확정 화면** — 장소·날짜·시간·이름·곡·키·추가 변경 사항을 티켓 모양 카드로 보여 주고,
   `예약 내역 복사`(클립보드 + 토스트)와 `확정증 이미지 저장`(Canvas로 그린 PNG, 길게 눌러 사진 저장 또는 내려받기)을 제공합니다.
4. **내 예약 확인 / 수정** — 상단 버튼에서 전화번호 뒷 4자리로 본인 확인 후 예약을 조회합니다.
   같은 기기에서는 `localStorage`에 마지막 예약을 기억해 상단 배너와 한 번에 열기 버튼을 보여 줍니다.
   예약확정 화면의 `예약 수정`에서 곡명·추가 변경 사항을 고치고, 비어 있는 다른 시간으로 옮길 수 있습니다
   (새 타임 선점 → 확인 → 기존 타임 해제, 동시성 안전).
5. **관리자** — 오른쪽 아래 `관리자` → PIN 입력 → 전체 명단(뒷자리 포함) 확인, 타임별 취소, `모든 신청 비우기`.

`?admin=1` 로 접속하면 PIN 입력창이 바로 열립니다.

## 파일

- `index.html` — 신청 페이지 전체(HTML/CSS/JS 한 파일)
- `mobile-preview.html` — PC에서 아이폰 폭(390px)으로 미리 보는 페이지
